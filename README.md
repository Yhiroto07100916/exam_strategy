# Exam Strategy

高校受験向けの成績・模試・単元別理解度・志望校目標を管理するWebアプリです。

## 起動

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn api.main:app --reload
```

ブラウザで http://127.0.0.1:8000 を開きます。API確認は `/api/health`。

現時点では認証・権限管理がありません。ローカルの信頼できる環境でのみ使用し、インターネットへ公開する前に認証・アクセス制御を実装してください。

## 機能

- ダッシュボード：最新模試、科目別得点率、目標との差
- 成績管理：科目別成績の登録・編集・削除
- 問題別管理：科目・単元・正誤・配点・獲得点の登録・編集・削除
- 単元別分析：配点が揃っている場合は得点率、そうでない場合は正答数ベースで集計
- 志望校・目標：科目別目標点と出典メモの保存
- 学校データベース：都県・公私・学校・年度・コース・選抜区分ごとの選抜情報と公式資料URLを管理
- 学校別目標点計算：確認済みの選抜ルールに記録した科目別素点・換算上限・調査書等の固定評価点から、目標選抜総合点に必要な科目別目標点を逆算
- 総合目標点の科目別配分：現在点・満点・学習優先度から科目別目標を計算し、満点に達した科目の余剰分を再配分
- 目標配分API：`POST /api/targets/allocate`（学校独自の公式配点や合格可能性を推定する機能ではありません）
- Excel / CSV一括取り込み（行ごとの入力エラー表示、重複検出、DB保存のトランザクション化）
- PDFテキスト抽出、ローカルTesseractによる画像PDFのOCR候補抽出・手動確認後の登録（OCR利用には日本語Tesseractデータが必要）
- Excelレポート出力
- SQLiteによるローカル保存（`data/exam_strategy.sqlite3`）

画像PDFのOCRを使う場合は、macOSで `brew install tesseract tesseract-lang` を実行し、日本語OCRデータ（jpn）を利用できる状態にしてください。OCR候補は自動保存せず、画面で日付・模試名・科目・得点・満点を確認してから登録します。

既存のCLIスクリプトは保持しています。`data/schools_template.json` は構造例であり、実在校の確定した選抜ルールではありません。学校別配点・合格最低点・合格可能性は年度や方式ごとの公式資料を確認してから扱ってください。学校データの「確認済み」は登録者による出典確認を示し、システムが公式サイトの真正性や内容を自動検証するものではありません。

## 学校別選抜ルールの計算形式

「確認済み」にする選抜ルールには、公式資料の該当ページを参照した `rule_data.scoring_model` が必要です。現在対応する形式は `weighted_components_v1` です。

```json
{
  "scoring_model": {
    "model_version": "weighted_components_v1",
    "exam_subjects": [
      {
        "subject": "数学",
        "raw_max_score": 100,
        "contribution_max_score": 150,
        "source_page": 12
      },
      {
        "subject": "英語",
        "raw_max_score": 100,
        "contribution_max_score": 150,
        "source_page": 12
      }
    ],
    "fixed_components": [
      {
        "name": "調査書",
        "max_score": 100,
        "source_page": 13
      }
    ]
  }
}
```

上記は形式説明用の架空データであり、実在校の配点ではありません。各科目の素点満点・選抜換算上限・固定評価項目の満点・出典ページは、登録対象の学校・学科・年度・選抜区分の公式資料から転記してください。

学校別計算APIは `POST /api/schools/{school_id}/rules/{rule_id}/allocate`。現在点、学習上の優先度、調査書等の実得点、目標選抜総合点を入力します。調査書等は入力した得点のまま固定して計算します。模試の得点率から換算した初期値は参考値であり、実際の入試得点を保証しません。

現行の計算形式は科目別の線形換算と固定評価項目に対応します。複数の算定方式のうち高い方を採用する制度、段階別評価、複雑な条件分岐などはまだ自動計算しません。該当する場合は方式ごとに公式ルールを分けて記録し、計算結果を比較する機能が整うまでは手動確認してください。
